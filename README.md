# daisuqe Apps

daisuqe が作ったアプリの一覧ページです。
https://daisuqe.github.io/

- アプリの追加・編集は `apps.js` を書き換えます。
- サムネイルは `thumbs/<slug>.png`(または .jpg / .webp)に置くと自動で表示されます。
- `apps.js` を変えたら、`index.html` の `apps.js?v=...` の番号も変えてください(ブラウザのキャッシュ対策)。
- `?lang=en` / `?lang=ja` を付けると表示言語を切り替えられます。
